場景 description 判斷準則（同 angles 一樣嘅硬性規定——呢個欄位會直接原封不動傳落去生圖做主圖嘅 base prompt）：
- description 淨係可以講環境本身——建築、傢俬陳設、光線、天氣、氛圍，**絕對唔可以出現任何人物**：角色名、代詞（佢／佢哋／她／他）、人類動作動詞（站、坐、敲門、等待、望向等）、或者表情/情緒詞一律禁止，同 angles 嘅 prompt 一樣嚴格。反面例子（絕對唔可以寫成噉樣，實測發生過真實事故）：「温馨的居家环境，有客厅和沙发，陈琳娜站在窗边，后有敲门声」——後半句「陈琳娜站在窗边，后有敲门声」係事件唔係環境，令生圖成日走出個人喺度，要刪走淨返環境部分，改寫做：「温馨的居家环境，有客厅和沙发，午后阳光透过窗户洒落」呢類先啱。
- **刪人物 ≠ 刪環境，唔准砍剩半句**：上面條規則叫你刪走人同事，唔係叫你連環境都一齊刪。刪完之後 description 仍然要**完整交代呢個空間長成點：20 至 60 字，最少講到建築／空間類型、傢俬陳設、光線或天氣三樣入面嘅兩樣**，而且要以完整句子收尾，唔准以逗號吊住。反面例子（實測事故）：見到反面示範之後索性寫成「温馨的居家环境，」就交貨——環境細節全部唔見咗，仲以逗號結尾；呢個欄位係場景主圖嘅 base prompt，寫得咁空即係叫生圖模型自己作間屋出嚟，成集場景就唔連戲。正解係保留晒環境部分：「温馨的居家环境，客厅中央一組布藝沙發，午后阳光透过窗户洒落」。

場景視角建議（angles）判斷準則：
- 重要場景定義：在劇本中出現於兩場或以上戲，或屬關鍵劇情發生地（衝突爆發、轉折、高潮場口）。
- 重要場景必須輸出至少 2 個 angles；普通場景 angles 一律輸出空陣列。
- 每個 angle 要填 reason（10 至 20 字），講返點解呢個場景值得建立呢個角度——照返上面兩個判斷準則之一嚟寫（例如「出現於3場戲」「衝突爆發嘅高潮場口」），純粹記低判斷依據，唔係畫面描述。
- label 須具體到空間關係（例：「吧台望向窗邊卡座」「巢穴入口望向祭壇」），只可以描述鏡頭喺邊個角度望向邊個方位，**唔可以用場口事件或劇情動作命名**（例如「巨龍對峙」「戰後交談」「XX到訪」呢類一律禁止——即使呢場戲嘅重要性正正嚟自嗰個事件都好，label 都只可以講空間，唔可以講劇情），**亦唔可以出現任何指涉人物嘅字眼**——唔止角色名，任何講緊「有人／有幾多人」嘅詞都唔啱（例如「眾人」「隊員們」「隊伍」「大家」「幾人」「幾女」「戰隊」「一行人」），用角色個人或者隊伍做參照點都算（例如「王楚所在位置」「隊伍後方」）。**label 唔止係俾人睇嘅標籤，佢會直接原封不動變成生圖 prompt 入面「reposition the camera to」呢句後面嗰段內容**——label 有人物字眼，個字眼就會直接傳落去生圖模型，同 prompt 出現人物係同一級數嘅事故。反面例子（實測發生過真實事故，絕對唔可以寫成噉樣）：「巨龍消亡后，眾人所在區域」、「王楚所在位置望向其他队员」——呢類講法係事件或者用人做參照點，唔係空間座標，應該改寫做純空間描述，例如「巢穴中央望向消散處」。
- **prompt 預設留空 `""`**——呢個角度嘅圖係以已鎖定嘅場景主圖做參考（圖生圖），材質/光線/整體氛圍主圖已經睇到，99% 情況你都應該輸出空字串。淨係得一種例外先可以填：劇本明確講到一件呢個角度先見到嘅**實物**（道具、牆身裝飾、地形特徵，例如「牆上掛住一幅畫」「地面有裂痕」），10 至 20 字內講清楚嗰件實物就夠，唔使句子。
- prompt **絕對唔可以**出現：角色名、代詞（佢／佢哋／她／他／幾女／眾人）、人類動作動詞（對峙、交談、舉劍、站立、奔跑、擁抱、等待、到訪等）、或者表情/情緒詞（驚訝、擔心、冷漠、喜色等）——凡係講緊「發生咗咩事」而唔係「呢度有咩實物」，一律唔啱，應該刪晒淨返 `""`。反面例子（絕對唔可以寫成噉樣，要改寫做空字串）：「陳琳娜獨自等待，望向窗外帶擔憂」「王楚到訪，陳琳娜由驚喜轉驚訝」「隊員間的對峙，王楚被孤立，隊員們神情冷漠」——呢三句冇任何主圖以外嘅實物細節，應該全部係 `""`。呢個場景嘅重要性可以嚟自劇情事件，但 prompt 淨係畀空鏡環境參考圖用，要當呢場戲入面所有人物完全唔存在咁樣去諗。
- 自我檢查（**label 同 prompt 各自逐個檢查一次先可以輸出，兩者同等重要，唔可以淨係查 prompt 唔查 label**）：讀返你啱啱寫嘅 label 同 prompt，如果入面有人名、代詞、動作動詞或者表情詞——唔係換個溫和講法，係即刻刪走重寫（prompt 改做 `""`，label 改做純空間描述）。唔好嘗試用委婉字眼去「洗白」個句子（例如將「等待」改做「望向」都仲係動作），凡係講緊人或者事而唔係講緊空間/實物本身，就係唔啱。
