前置過濾（實物 vs 抽象，先過呢關先入三級分類）：
只抽取實物道具——道具必須係劇中角色可以擁有、拿起、觸碰、或者肉眼可見嘅實體物件（武器、器具、法器、信物、擺設等）。以下呢啲一律唔算道具，唔可以抽：
- **著喺身上嘅服裝**（衫褲裙袍、浴袍、鞋帽、披風、盔甲）——屬角色嘅 wardrobe，由角色抽取負責，喺呢度再抽就係同一件嘢兩處表述。分界線：**攞喺手嘅係道具，著喺身上嘅唔係**；手持武器器具就一定要喺呢度抽。
- 遊戲機制、系統提示、天賦、技能名稱（例如「女神連結」「萬物融匯」「B級天賦」）
- 數值增益/減益效果（例如「全屬性增加20%」「BUFF」「Debuff」）
- 抽象概念、稱號、等級（例如「SSS級」「隱藏成就」）
- 有生命嘅生物、怪物、NPC、坐騎（例如「巨龍」「魔物」）——呢啲屬於角色/生物範疇，唔係道具，即使劇本入面淨係當場景障礙出現、冇被抽做 Character 資產都好，一樣唔可以當道具抽

description 同必填欄位（description 會**原封不動**串成道具生圖 prompt 嘅主體描述）：
- description 只准講**件物件本身**（造型、材質、顏色、紋樣、狀態），**絕對唔可以出現人物**：角色名、代詞，以及「XX 穿着的」「XX 手裡握着的」呢類用人做參照點嘅講法，動作動詞同情緒詞一律禁止。道具圖係純白背景單件物件，明文寫住 no people／no hands，寫住「陈琳娜穿着的浴袍」就係一邊叫模型畫人一邊叫佢唔准畫人。反面例子（實測事故）：「陈琳娜穿着的浴袍。」→「白色浴袍」；「郑夏雨高举的长剑，剑尖圣光冲天。」→「一把冷白色聖銀長劍，劍身泛聖光」。
- material、dimensions **必填**：劇本冇明講就按道具性質同時代背景推斷一個具體答案（「羊脂白玉」「約 90 公分長」）。**推斷唔到就唔好抽呢件道具**，唔准寫「未知」「不明」「未提及」——嗰啲字眼會原樣串入生圖 prompt 變成空槽，出圖冇一致錨點。tier=effect 例外：光效冇實體尺寸，dimensions 可留空，改為 physicalParams 必填。

例外：如果呢類抽象效果喺劇本入面有明確、具體嘅視覺化呈現（例如「掌心浮現一團藍白色能量光球」「符文浮現並發光」），咁呢個視覺效果本身可以做 tier=effect 道具抽出嚟——但抽嘅係「你睇到嘅光效/異象」，唔係抽個技能個名。命名時用視覺描述（例如「掌心能量光球」）唔好用遊戲術語（唔好叫「女神連結技能」）。

三級分類判斷準則：
- tier=key（關鍵敘事道具）：高頻使用、劇情核心、不可替換（信物、專屬武器、定情信物一類）。views 必須輸出剛好 4 個，label 依次固定用「正面」「反面」「側面」「細節特寫」。
  - prompt 要求外觀「焊死」——材質、尺寸、紋樣具體到位，**禁止用含糊字眼**（例如「未知」「可能」「或者」「大概」「似乎」），呢啲字眼會令下游生圖失去一致嘅錨點。
  - views 嘅 prompt **並非必填**——四個角度（正/反/側/細節特寫）本身已經有固定嘅生成指示，唔使你每個都作一句描述。**淨係喺劇本入面真係有講明呢個特定角度先至見到嘅具體細節**（例如「反面刻有龍紋」、「劍柄纏繞金絲」）先至填 prompt；冇明確依據就留返空字串 `""`，**唔可以自己作一句「可能刻有符文」「大概有紋飾」呢類猜測性描述**——寧願留空都好過寫含糊猜測，猜測性文字會拖累下游生圖嘅一致性。
- tier=scene（場景填充道具）：中頻使用、環境支撐（桌椅、餐具、書籍一類）。sceneName 填返呢件道具主要出現嗰個場景嘅地點名（同劇本場口標題一致）；views 可以輸出 0 至 1 個，material 可以粗略但都要係具體字眼（唔可以寫「未知」）。
- tier=effect（動態特效道具）：低頻使用、視覺衝擊（魔法光效、能量護盾、爆炸一類）。views 輸出 1 至 2 個靜態關鍵幀參考；physicalParams 必填，描述強度、顏色、持續時間、擴散方式（例：「亮度高、藍白色、持續 2 秒、由掌心向外擴散」）。
